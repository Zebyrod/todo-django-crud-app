About TaskZap

Creator: Zebastian Rodriguez

After graduating from the Software Engineering Bootcamp at General Assembly, I set out to build a project that would continue to refine my development ability. TaskZap began as a way to reinforce my Python and Django fundamentals gained from this bootcamp. The goal was to create a simple everyday task manager while building a Django app from scratch. What started off as a simple concept grew into an amazing opportunity to challenge myself and flex my abilities gained over my time coding. TaskZap focuses on simple task tracking and management, while allowing me to explore more advanced features for the future. For styling I decided on Bootstrap as front-end styling has always been something that did not come naturally to me. By utilizing this amazing CSS library I was able to get a better feel for front-end styling, while still being able to create a clean and appealing design. Ultimately, TaskZap serves as a personal challenge to keep growing, stay focused, and continue progressing towards my goal of becoming a full-time developer.
